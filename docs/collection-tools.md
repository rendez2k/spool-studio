# Collection sorting and batch actions

Collection and List offer **Sort by**: purchase date or added/imported date, newest or oldest first. Default order preserves the original view. Grouped cards use the latest member date for newest-first and the earliest for oldest-first. Their date caption identifies which one is shown. Missing dates stay last; historic import dates were not recorded and are not inferred from purchase dates. Newly added and reviewed-import entries receive a server timestamp that edits do not reset.

Choose **Select entries**, tick cards or list entries, then **Bulk edit** or **Print selected labels**. Grouped cards select all their underlying purchase entries, including entries beyond the current page. **Select all results** selects all filtered results, not just this page. Filter changes discard selections that no longer match; changing to Colour shelf or Match a print clears the selection. Selection is temporary and does not sync to other devices.

Bulk edit updates only filled fields: brand, product/type, material, finish, packaging, purchase date and replacement notes. Blank means unchanged. Review the selected-entry list before saving. Roll quantities, weights, usage, import timestamps and permanent spool IDs are never bulk changed. The server validates the complete request, checks the owner and library revision, and saves all entries together or none. If the library changes elsewhere, reopen the editor and review again.

Selected labels include available counted rolls only, excluding used-up reels and uncounted bundles. They use the existing size/copy/QR preview and print flow, including 60 × 30 mm and MUNBYN 76 × 50 mm. Choose two copies for the box and spool. First/last selected-roll inputs index the chosen subset; printed shelf positions are not renumbered within that subset. Positions come from the entire available library with the current Colour shelf sort/size, regardless of Collection filters or date sorting. For labels matching a filtered shelf arrangement, use **Colour shelf → Print shelf labels** instead.

Permanent SP numbers and QR links remain tied to their original physical reel. Without permanent IDs, labels show temporary shelf positions only. The missing-ID warning offers **Assign permanent IDs to my rolls** directly in the label panel. This explicit action initialises all counted rolls in the library, not just the selected labels, preserving quantities and used marks. It uses the existing account/revision-checked, idempotent library action. Success refreshes the snapshot and QR preview without resetting label settings or starting printing; failures stay beside the button. Physical spools & usage remains an alternative. Printing itself neither edits stock nor assigns IDs. Label batches are limited to 500 printed labels including copies, and a changed library or selection requires refreshing the preview. Real printer alignment and phone scanning still need device testing.
