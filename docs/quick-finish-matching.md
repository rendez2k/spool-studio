# Quick finish matching

In **Match a print**, a model with selected colours whose finish is unknown shows **Use finish** and **Match unknown finishes** above its matches. Pick Standard / basic, Matte or another known finish, then apply. This is the user's requested finish, not an inferred manufacturer fact.

Only included unknown-finish slots in the current project change. Known finishes, excluded slots, other loaded projects, original files and library stock stay unchanged. Matches recalculate; changed slots lose any previously chosen filament, requiring a fresh choice before phone transfer or remapping. Existing phone sync follows its normal reviewed-choice state; no printer command is sent.

Each colour also has a visible **Requested finish** selector beneath its heading, without opening More options. This permits individual corrections, including returning a slot to Unknown finish. Choices last for the loaded project session.
