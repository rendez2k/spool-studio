Spool Studio Bridge

Choose filament on your phone. Send it through the computer beside your printer.

Install the bridge once on a Windows PC or Mac on your printer’s network. You do not need a GitHub account, access to someone else’s repository or Node.js.

Three steps, then you’re connected

  1. Create your connection. Open Printer → Local bridge setup, create a printer key and enter your printer’s local address. Download the private printer configuration on the bridge computer.
  2. Import and check. Open the desktop app, choose Import configuration and select that downloaded JSON. Choose Check connection. This only reads the printer; it does not change filament settings.
  3. Start the bridge. Keep the computer awake. On your phone or desktop, choose a filament and tool in Spool Studio, review the change and send it. Check the read-back result before assuming it worked.

Closing the window keeps the bridge in the tray/menu bar. Stop prevents new requests and lets an in-flight request finish. Quit exits the app. On Windows, enable Start with Windows and reconnect automatically once in the desktop app. It starts in the tray after you sign in, checks the printer and retries every 30 seconds if the printer or network is unavailable. Stop cancels retries for this session; untick the option to disable future automatic starts. The computer must stay awake. This is not a service running before sign-in. macOS still requires a manual check/start.

What stays local

The bridge makes outbound connections; no port forwarding or public printer address is needed. It supports the U1 firmware’s checked filament-metadata commands. Printing, paused or unknown states block changes. It does not send heating, motion or print-start commands.

Your imported configuration is encrypted using the operating system’s secure storage. The original downloaded JSON still contains a secret: keep it private, never share it, and delete it when no longer needed. Remove configuration clears the desktop copy; revoke the key on the website to disable it.

This is not the weight-sync bridge. It sends reviewed material/colour settings and can assign an already-linked Spoolman reel. Spoolman consumption recording and syncing remaining weights into your library are separate. Do not run this and the command-line printer bridge with the same key.

Advanced: Docker or source

Docker · Linux amd64

Use a computer or NAS on the printer’s network with Docker Compose. Download compose.yaml and place your downloaded spool-studio-printer.private.json beside it. Do not paste your key into a shared compose file.

docker compose run --rm spool-studio-bridge --check
docker compose up -d
docker compose logs --tail 30 spool-studio-bridge
docker compose down

The first command is a read-only check; run the second only after it succeeds. The last command stops the service. No inbound ports are published. On Linux, the private file must be readable by container user 1000 without making it world-readable. Docker restarts this service with Docker unless you stop it. ARM/Pi images are not included in this beta.

Run from source

The public repository is downloadable by anyone; ownership is not required. Developer commands, Node prerequisites and safety details are in the source setup guide.
